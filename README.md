# E-commerce Sales Data Analysis

## 1. Project Overview
E-commerce Sales Data Analysis is a Python-based project that analyzes sales data to understand revenue, product category performance, regional sales, and customer ratings. The project uses data analysis techniques and visualizations to present useful business insights.

## 2. Objectives
- Analyze overall sales and revenue.
- Calculate total quantity sold, orders, and customers.
- Identify revenue generated by different product categories.
- Analyze revenue trends over time.
- Compare revenue across different regions.
- Visualize the distribution of customer ratings.

## 3. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## 4. Dataset
The project uses an e-commerce sales dataset containing order details, dates, product categories, revenue, quantities, customer information, regions, and customer ratings.

## 5. Methodology
1. Import the required Python libraries.
2. Upload and load the dataset.
3. Explore the dataset structure and column names.
4. Check missing values and duplicate records.
5. Convert order dates into datetime format.
6. Calculate overall sales statistics.
7. Group and analyze revenue by category, date, and region.
8. Generate charts to visualize the results.

## 6. Visualizations
- **Bar Chart:** Revenue by product category.
- **Line Chart:** Revenue trend over time.
- **Bar Chart:** Revenue by region.
- **Pie Chart:** Revenue contribution by product category.
- **Box Plot:** Distribution of customer ratings.

## 7. How to Run the Project
1. Open the Jupyter notebook in Google Colab.
2. Upload the provided CSV dataset when prompted.
3. Execute the notebook cells in order.
4. Review the calculated sales summary and generated charts.

## 8. Expected Outcome
The project helps understand sales performance, compare product categories and regions, identify revenue trends, and examine customer rating distributions.

## 9. Conclusion
This project demonstrates how Python libraries can be used to analyze e-commerce sales data and represent findings through charts. The analysis supports a better understanding of sales patterns and business performance.
